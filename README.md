# Портфолио — Наталия Терещенко

Сайт: https://whimstation.github.io/portfolio/

| Ссылка | Для каких вакансий |
|---|---|
| `/portfolio/` | общая — арт-директор |
| `/portfolio/creative/` | режиссура, моушн, видео |
| `/portfolio/writing/` | редактор, кинокритик, тексты |
| `/portfolio/product/` | AI-продакшн, performance-креативы, продукт |

Английская версия любой ссылки: добавьте `?lang=en` (например `/portfolio/product/?lang=en`).

## Как сделать версию под конкретную вакансию
1. Откройте `src/site.json` на GitHub (карандаш «Edit»).
2. Скопируйте любой блок в `versions` и поменяйте: `id` (станет адресом, например `ozon`), `title`, `role`, `intro`, порядок `cases` и `sections`, абзацы `about`.
3. Нажмите «Commit changes». Через 1–2 минуты сайт пересоберётся сам: `/portfolio/ozon/`.

## Видео
Все ролики лежат в `media/` как лёгкие MP4 и играют прямо на сайте — без YouTube и Google Drive, без VPN.
Новое видео: добавьте строку в `src/media.json` (ссылка на Drive или YouTube) и вставьте `[[tile:имя]]` в нужный кейс в `src/cases/`. Робот сам скачает, сожмёт и сделает обложку.
Если ролик скачать не удалось, его имя будет в `media/_missing.txt` — тогда загрузите файл `имя.mp4` в папку `media/` вручную.
